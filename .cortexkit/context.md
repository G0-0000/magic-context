# Magic Context 项目参考文档

本文件为直忆（strata-ask）存盘语料之固定参考文档，置于项目 git 根；记忆库语料节（【项目参考文档】）整节读取本文件。内容为稳定方向与名词口径，不随版本细节变动。

## 项目介绍

Magic Context 是长会话编码代理的上下文窗口管理器：在不丢失历史的前提下把会话保持在模型窗口内，同时保持提供商提示词缓存稳定——长会话里缓存前缀即主要成本。它以 OpenCode 插件（`packages/plugin`，TypeScript 核心本体）、Pi/OMP 插件（`packages/pi-plugin`）两种宿主形态发布；全机所有宿主共用一份 SQLite 数据库 `context.db`。

宿主内模式（OpenCode/Pi/OMP 插件宿主）下，系统在每次模型调用前重写即将发送的消息数组与系统提示词；变换本身不调用模型，摘要与后台维护在隐藏子会话中运行。会话页首的归约、历史与记忆全部按既定车道落在此重写之内。模式 3（会话托管于 llm-runner）不在此列：变换以「视图」增量发布、由 runner 应用到每个请求，不逐请求整列重写。

## 本体

- **标签与归约**：每条消息部件与工具输出带 `§N§` 标签；代理用 `ctx_reduce` 标记不再需要的内容，已标记项随后搭一次本来就要重建缓存前缀的变换趟落地。被丢的文本部件留下 `[dropped §N§]` 占位；任何原文都可用 `ctx_expand` 从原始历史完整找回。
- **历史**：史官把较早的原始历史分块写成「分室」摘要，每室四个细节层级并配重要性分数；确定性渲染器按室龄、重要性与当前预算各选一档，历史随年龄优雅退化。
- **提示词头部**：分室、记忆、项目文档与用户画像渲染为开头两条合成用户消息——m[0] 为冻结基线，m[1] 为自上次基线重建以来的增量，两类内容分槽承载，大段稳定前缀得以长期缓存。
- **知识**：`ctx_memory` 写项目记忆（项目级共享）；`ctx_note` 记便签；`ctx_search` 统一检索记忆、会话历史、git 提交与便签；`ctx_expand` 取回原文。
- **压力**：常规归约只搭便车于本来发生的缓存重建，不主动破缓存；接近上限有强制带（约 85%）；实测 95% 且无可折叠内容时拒发请求，而不是把超限请求发出。

## 名词规范

- **变换趟（pass）**：一次变换运行。宿主内模式每个模型请求恰跑一次；模式 3 下只在 Setup、消息通知或缓存失效搭车时运行，未获新视图的步天然视为命中趟。
- **缓存重建（bust）**：改变缓存前缀内部字节的趟；按可深入前缀的位置分三级——SOFT+ 只动 m[1] 之后的对话；SOFT 重渲染 m[1]；HARD 重渲染 m[0]（折叠）。
- **缓存命中趟（defer pass）**：不 bust 的趟；逐字节重放早先决定、仅追加新消息。稳态下绝大多数趟是此类。
- **分室（compartment）**：一段工作过程的摘要单位，由史官产出并发布；发布本身不 bust 缓存。
- **史官（historian）**：把旧原始历史摘要成分室的隐藏子会话。
- **梦工（dreamer）**：进程级定时器，按 cron 调度后台维护任务（校验记忆、策展分类等），任务失败自动重试。
- **主会话 / 子代理**：人直接工作的会话为主会话；由其他代理启动的为子代理。两者归约车道不同：主会话的重建许可来自自然 bust 或受限的执行趟，子代理的每个执行趟即是重建许可。
- **直忆（strata_ask）**：裸 `ctx_search` 查询可由用户配置的 Strata 会话文件缓存（存盘语料）应答；写侧仅在一次完整重建时重读项目参考文档（本文件），查询侧不读本文件；但查询侧每次查询会读盘读取旁侧变更流水台账以载回尚未固化的记忆变更（台账缺失、不可读或不完整时，该次查询回落经典检索）；档之建立与每日重建由维护任务负责。
- **记忆**：项目级事实，分五类（项目规则、架构、约束、配置值、命名）；新增经 m[1] 增量进入提示词，下次自然重建时折入 m[0]。

## 俗称对照

检索问答中用户惯用俗称，与档、码用词对照如下；答问时两套词可互训。

| 俗称 | 档/码用词 | 释义 |
|---|---|---|
| 直忆 | strata_ask / save file | 以 Strata 会话文件缓存应答裸 ctx_search 查询的通道 |
| 档 | save file / 存盘语料 | Strata 侧保存的会话文件，内含记忆库与本参考文档 |
| 旁档 | sidecar / `*.tokens.json` | 与档同目录的令牌旁档，缺失则首次 splice 必 409 |
| 缝合 | splice | 查询时把新消息接进已存前缀复用缓存的机制 |
| 固化 | consolidate | 把旁侧变更流水台账里的记忆变更并入档 |
| 台账 | 变更流水 | 记忆变更的旁侧记录，查询侧读它以载回未固化变更 |
| 重建 | rebuild | 全量重组档语料并重读本文件；每日 8:30 维护任务执行 |
| 建档门槛 | creation threshold | 记忆量过小不建槽的阈值；存在本参考文件可豁免 |
| 回落 | fallback | 台账缺失或不完整时，该次查询退回经典检索 |
| 早班 | dream 早班队列 | 每日清晨一串按时刻表运行的 dreamer 维护任务 |

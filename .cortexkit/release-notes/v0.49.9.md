# v0.49.9

This patch release keeps tool-output cleanup aligned with the conversation, improves large-session handling on Pi, adds free OpenCode Zen models to history summarization, and fixes several host and release details. There is no database migration.

## Upgrading

- **No migration.** `context.db` stays at schema 95 and `store.db` at schema 63. Restart OpenCode 1, OpenCode 2, Pi or Oh My Pi after updating.
- **Rust-mode installs need to update `ck-mc` to the version shipped with this release.** The Rust module, not just the host plugin, contains age-based reclaim and the raw-replay fix; the latter prevents a rare large cached-prefix rewrite when a saved replay ends.

## Fixed

- **Tool outputs now age by conversation distance:** after three user turns or 25% of the context window, rather than by elapsed idle time. Short pauses and model switches no longer clear work that still belongs to the current task (#700).
- **Large Pi sessions no longer stall while measuring dropped tool output on direct providers.** The native Pi API path still measures the full metadata (#704).
- **After a provider rejects a signed-thinking block, Pi strips the rejected block once.** Providers cache the conversation prefix; Pi replays the corrected request byte-for-byte so that cached prefix stays unchanged.
- **OpenCode Zen free models can summarize history on OpenCode 1 and OpenCode 2.** Pi and Oh My Pi now report a clear reason when those models are unavailable (#495, #481).
- **`/ctx-status` on OpenCode 2 shows the session model's own threshold.** This change was contributed by @manorit2001 in PR #706 (#705).
- **`ck module status` reports the actual `ck-mc` release version (#710).**
- **Smart-note scheduling handles sparse cron runs, and primer candidates are ordered consistently.**

# v0.49.17

This release reduces maintenance log noise while preserving slow-transform diagnostics. It also cleans up stale discovery and project records and bounds rate-limited background embedding work.

## Fixed

- Transform timings now use one summary per pass, with slow stages still logged individually (#746, thanks @null-axiom).
- System-prompt changes identify changed elements using hashes, byte lengths and offsets, never prompt content (#746, thanks @null-axiom).
- Maintenance prunes project identity records only when their directories are definitely gone (#746, thanks @null-axiom).
- Non-git projects skip commit probes and log once per parking interval instead of every maintenance tick (#747, thanks @null-axiom).
- Session deletion avoids unnecessary fence locks and removes empty lock directories after cleanup (#746, thanks @null-axiom).
- RPC startup reaps dead discovery records, and shutdown removes empty project discovery directories (#746, thanks @null-axiom).
- Background embedding batches yield after repeated rate limits; commit embedding sweeps now abort at their five-minute deadline (#746, thanks @null-axiom).
- General maintenance ticks no longer use the misleading dreamer log prefix (#746, thanks @null-axiom).

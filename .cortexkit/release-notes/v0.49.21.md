# v0.49.21

## Optional hosted reranking for explicit search

Thanks to @XWIlluDelu for proposing direct hosted reranking for `ctx_search` (#765).

- OpenCode and Pi can opt into Cohere-compatible or Hugging Face TEI rerank APIs through a user-level `rerank` block, with environment-based API keys, bounded requests and cancellation.
- Local Synapse stays the default. Hosted failures preserve the original search order and show a short, redacted skip reason; automatic per-turn hints never make hosted rerank calls.
- Project configs may only turn reranking off, never redirect private search text or supply credentials. Doctor summarizes the selection without exposing secrets.
- Removed the ignored `accept_declared` field from Synapse rerank and embedding requests.

The dashboard's Raw JSONC editor supports the new settings; a dedicated hosted-reranker form remains a follow-up.
## Fixed

- Oh My Pi Responses sessions continue after tag stripping, including saved history and forked sessions. Thanks to @sisttri for the report (#766).

## Upgrading

- Restart Oh My Pi after updating. No database migration is needed.
- Local embedding workers now shut down after 10 minutes without work and restart lazily on the next request. OpenCode 2 also releases project embeddings when the last location context using them is disposed. This releases the model process's native memory instead of retaining it indefinitely. Thanks to @LouisLau-art for the detailed memory report in #767.
- Documentation maintenance now retries malformed proposals with the configured fallback and recognizes whitespace-padded or fenced empty arrays (#768, thanks @breakbeatkid).

# v0.49.26

This patch stops Magic Context from serving an old copy of text another OpenCode plugin adds to your messages.

## Upgrading

- Restart OpenCode after updating. No database migration is needed.

## Fixed

- **Text another plugin adds on OpenCode 1:** some plugins add a text part to the current message on every step, for example a marker that changes from step to step. Magic Context treated that part as part of the conversation: it numbered it, saved its text, and on later steps put the saved copy back. The plugin's current text was replaced by an older one, which the plugin could then refuse.
  - **New parts:** text another plugin adds is now left exactly as that plugin wrote it. It's never numbered, saved or restored, and `ctx_reduce` skips its id.
  - **Existing sessions:** a part an older release already numbered keeps the bytes that release sent while the plugin's text is unchanged, so the upgrade doesn't break the prompt cache.

  OpenCode 2, Pi and Oh My Pi are unaffected.

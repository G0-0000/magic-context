# v0.49.20

This patch release fixes incorrect local embedding vectors for models that declare CLS or other non-mean pooling.

## Fixed

- The local embedding provider now follows each model's declared pooling and normalization, keeping BGE vectors aligned with the sentence-transformers pooling rule; memories and git commits re-embed in the background, while inactive-session history vectors stay out of semantic search until that session runs `/ctx-embed start` (issue link: [753](https://github.com/cortexkit/magic-context/issues/753), thanks @LouisLau-art).
